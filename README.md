# 🍕 QuickBite – Food Delivery Platform

## 📌 Project Overview

QuickBite is a modern and responsive food delivery platform designed to help users discover food, view food details, manage their cart, complete checkout, and place orders.

The platform provides a clean and interactive interface for browsing popular food, searching food items, selecting quantities, reviewing order summaries, entering delivery information, choosing payment methods, and viewing order confirmation.

## 🚀 Key Features

- Login and Sign Up interface
- Food Delivery Home interface
- Food Search functionality
- Food Categories
- Popular Food section
- Food Details interface
- Food description and pricing
- Quantity Management
- Add to Cart functionality
- Shopping Cart
- Order Summary
- Dynamic Cart Total Calculation
- Checkout interface
- Delivery Information
- Phone Number input
- Payment Method selection
- Order Placement
- Order Confirmation
- Order ID and Estimated Delivery information
- Back and Navigation controls
- Responsive design for desktop, tablet, and mobile

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- CSS Flexbox
- Responsive Web Design
